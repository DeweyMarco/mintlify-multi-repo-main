description: "How one base repository combines two independently deployed documentation sites."

This site demonstrates a Mintlify multi-repo setup. The base repository owns the shared site configuration and this guide, while two child repositories own their API code and documentation.

Each child is used in two places: it has its own Mintlify deployment for focused previews and automations, and it is also mounted into this combined site for readers who want one documentation experience.
